Zoodopt

Plataforma de adopción de mascotas · Full stack

Los usuarios pueden ver las mascotas en adopción y postular en línea; el personal del refugio puede administrar los anuncios y revisar las solicitudes.

  • Autenticación con JWT y acceso basado en roles para el público, el personal del refugio y los administradores
  • Interfaz en React, accesible y adaptable, sobre una API en ASP.NET Core
  • React
  • ASP.NET Core
  • PostgreSQL

Cocktail Finder

Aplicación web basada en una API

La app muestra un cóctel al azar y su receta completa cada vez que se carga la página. Permite buscar por nombre o filtrar por categoría, ingrediente o tipo con la API de TheCocktailDB.

  • Servidor Express con plantillas EJS que renderizan los resultados en el servidor
  • Convierte los 15 campos separados de ingredientes y medidas de la API en listas de receta ordenadas
  • Node.js
  • Express
  • EJS
  • API REST

Book Notes

Registro de lecturas con base de datos

Busca libros en la API de Open Library. La app permite agregarlos con su portada y luego escribir, calificar, editar o eliminar reseñas guardadas en PostgreSQL.

  • Flujo completo de creación, lectura, actualización y eliminación (CRUD)
  • Consultas SQL parametrizadas para mantener los datos del usuario fuera del texto de la consulta
  • Node.js
  • Express
  • PostgreSQL
  • EJS
